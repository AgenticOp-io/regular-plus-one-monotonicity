# r46: do the gap-3 per-step errors add coherently? -- r45's L^6/n^2 is a unit error; shift is O(L^4/n^2) at 2nd-order level

Script: `v2/scripts/r46_gamma_formula.py` (float64, linear regime, x=2, n=1e4..1e8, L<=1000, L^2<=n/2). Nothing edits main.tex/STATUS.

## 1. Unit error in r45 (PROVED, bookkeeping)
r36 s3: ln Z_j = ln Z_j(m=0) + gamma_j m_j. r41 s4's L^3/n^2 is the error in ln Z_j per factor (dropped terms L m/n^2 with m~L^2),
i.e. delta_gamma * m ~ L^3/n^2, so the error in the *slope* gamma_k is delta_gamma ~ L/n^2 at most (m~L^2).
r45 added delta = L^3/n^2 to every gamma_k, i.e. counted the m-factor twice. With delta_gamma = c L/n^2 r45's own
response dS ~ (L^3/3)*delta gives c L^4/n^2, not L^6/n^2. So r45's "range L=o(n^{1/3})" claim is FALSE as stated (conditional on this slope bound).

## 2. True delta_gamma from the second-order formula (NUMERICS + analytic formula, r36 s2)
Using d/dm of ln Z = q1 W1 + (q2-q1^2)W1^2/2 - q2(Q2/2+P2) (regular F deg L, U deg j-1, uniform overlap o=2m/n, m=jL/2, y=1.5):
delta_gamma = gamma_formula - (-(y-1)/(n-1)) satisfies delta_gamma*n^2/L = 0.037, 0.012, 0.004, 0.001 for L=10,30,100,300,
i.e. delta_gamma ~ 0.37/n^2, **independent of L** (even better than L/n^2: the L/n^2 pieces from (q2-q1^2)W1 and q2*d(P2) cancel;
sketch of why: s_v^2 terms cancel as in r36 s2). Sign: deterministic, one sign (positive), so it adds coherently -- but it is tiny.

## 3. Total shift (NUMERICS, second-order gamma)
Backward recursion y_j = x exp(sum_{k>j} gamma_k(y_k)) with true-formula gamma vs leading gamma; S=sum_j j(y_j-1) proxy:
dS * n^2/L^4 = 0.082 (n=1e4..1e6, all L), 0.07-0.11 (n=1e8). So dS ~ 0.083 L^4/n^2 = o(1) for L=o(n^{1/2}). No cancellation needed:
the error is not L^6/n^2; it is the L^4/n^2 already known (r41's remainder order). Random signs irrelevant at this order.

Verdict: gap 3 reduces to gap 2: with k<=2 clusters the shift is O(L^4/n^2), range o(n^{1/2}); r45's n^{1/3} limit is NOT intrinsic.

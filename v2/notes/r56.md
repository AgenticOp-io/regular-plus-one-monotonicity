# r56 — lemma (M): no proof; exact numerics extended to n=40, D<=10 (supports err ~ c·D/n^2, linear in D)

Scope: this note + `v2/scripts/r56_dp.py`. Nothing proved. Labels: proved / sketch / false / open.

## Analytic attack on (M): not obtained
No new route closed (M). Differentiable Isaev-McKay and KP at D<=c n^{1/4} both reduce to the same uniform
quartic/sextic cumulant remainder bound already identified in r53 (no published uniform-in-d bound). I did not find a
bound that avoids it. Status of (M): **open**.

## Numerics (new, exact; `python v2/scripts/r56_dp.py D n1 n2 ...`)
Exact N(d) by a vertex-by-vertex DP whose state is the histogram of residual degrees of unprocessed vertices
(poly in n, replaces the edge-DP of r53 which is exponential). Self-check asserts on tiny cases; reproduces r53's
n<=10 values to 5 digits. Test: err = [lnP(d')-lnP(d)] - [G0(d')-G0(d)], d regular, d' = d with B/2 pairs
(+1,-1). norm = err·n^2/(B(D+B)).
- D=3: n=8,10,20,40, B=2 norm -0.54,-0.48,-0.38,-0.35 (err -.0838,-.0479,-.00955,-.00217)
- D=4: n=10,20,30 B=2 norm -0.64,-0.46,-0.42
- D=6: n=20,30 B=2 norm -0.59,-0.51 ; D=8 n=20: -0.73 ; D=10 n=20: -0.91
- B=4, B=8 norms are smaller in magnitude and shrink with n (e.g. D=3,n=40: B4 -0.25, B8 -0.16).
Observations (empirical only):
1. err scales as n^-2 at fixed D (D=3, n 20->40: ratio 4.4; D=6, n 20->30: ratio 2.6 vs 2.25 for n^-2).
2. Large-n coefficient n^2·err/B is ~ -1.74 (D=3,n=40), -2.49 (D=4,n=30), -4.04 (D=6,n=30): roughly linear in D
   (slope ~0.76/unit), NOT quadratic. This is consistent with the target O(D/n^2) with a negative constant.
3. At D/n=1/2 the normalised error drifts up with D (finite-size, D~n regime), so no claim for D comparable to n.
4. Additivity in B is sublinear (B=8 err < 4×B=2 err per n^2/(B(D+B))), consistent with the B(D+B)/n^2 form.
Limits: n<=40, D<=10, regular base only, B<=8. D=8,10 at n>=30 not finished (timeout). Not evidence for D<=n^c.

## Outcome
(M) still open. Contribution: scalable exact counter (n=40 feasible) and data supporting an error of exact order
-c·D·B/n^2 with c≈0.4 (per unit D·B, large n), useful as a target constant for any proof of (M).

3. VERDICT ON THE LITERAL CONJECTURE (item (iii), uniform over all G0)
   - Dense fixed p (D fixed): consistent with literal flatness; per-triangle effect dies faster
     than 1/n (p=3/4).  Not the paper's regime.
   - Fixed host mean degree (rho fixed), which is the local structure of the paper's regime:
     the per-triangle penalty 1-theta ~ 0.055 does NOT shrink with n (n=7..10).  Then the
     type with ~n/3 triangles has a/a(C_n) ~ theta^{n/3} -> 0, so max/min a -> infinity.
     LITERAL (iii) EXPECTED FALSE.  Heuristic for D -> infinity (paper regime): a planted
     k-cycle in G0 changes N(G0 u R) by a factor 1+eta_k that is local (n-independent) once
     np = O(D); the extremal D-regular G0 (disjoint K_{D+1}'s) has ~nD^2/6 triangles, so
     uniform flatness would need |eta_3| = o(1/(n D^2)), which a local quantity cannot satisfy.
     STATUS: numerical + heuristic, NOT proven.  The finite-n failure is already exact
     (rem:small-n-inv, prop:zd-not-flat); this adds that it does not wash out with n in the
     rho-fixed regime.
   - Also note: at FIXED D the rho-fixed TV itself stalls (~0.009 at n=8..10), as predicted by
     a Poisson triangle model: t3 ~ Poi((D-1)^3/6)=Poi(1/6), Y = theta^{t3}/E theta^{t3},
     theta=0.94 gives (1/2)E|Y-1| ~ 0.008.  So for fixed D even the normalized statement
     fails; it can only hold with D -> infinity (as in the paper).  (Fixed D, rho fixed is
     degenerate anyway: P(N>=1) -> 0, isolated vertices.)

4. NORMALIZED REFORMULATION (proposed replacement for item (iii))
   (iii')  a(G0) = (1+o(1)) abar   for all G0 outside a set of mu_D-mass o(1),
           where abar := E_{mu_D} a = P(N>=1) / (|Omega_D| p^{Dn/2})   (= c_n of prop:target-cn).
   CLAIM (proven, elementary): (iii') <=> d_TV(nu_D, mu_D) -> 0.
     Proof.  prop:nu-rn gives d nu_D/d mu_D = Y := a/abar exactly (checked exactly in the
     selfcheck at n=6, two p).  Y >= 0, E_mu Y = 1, so d_TV = (1/2)E|Y-1| = E(1-Y)^+ .
     (=>) E(1-Y)^+ <= eta + mu(Y < 1-eta) -> eta for every eta>0.  (<=) Markov:
     mu(|Y-1|>eta) <= 2 d_TV / eta.  No assumption P(N>=1) -> 1 is needed.
   SUFFICES FOR THE DOWNSTREAM USE: item (iv) / conj:config-split only use d_TV(nu_D,mu_D) -> 0
     (triangle inequality with d_TV(L_{d,m}, nu_D) -> 0), and conj:Q is a coupling with o(1)
     failure, which only consumes total-variation statements.  So (iii') can replace (iii)
     with no loss anywhere in the chain; the uniform version was never needed, and is
     (per section 3) likely false.
   WHAT (iii') NEEDS in the paper regime (heuristic, from the multiplicative structure):
     with a/abar ~ prod_k (1+eta_k)^{X_k(G0) - E X_k}, X_k ~ Poi((D-1)^k/2k) under mu_D,
     TV -> 0 iff sum_k (D-1)^k eta_k^2 / 2k -> 0, i.e. |eta_k| = o(D^{-k/2}).  This is a
     small-subgraph-conditioning condition, far weaker than the uniform |eta_3| = o(1/(nD^2)).
   Exact-arithmetic evidence at small n: section 1 (identity), section 2 (TV row) -- the
   identity is exact; whether TV -> 0 in the paper regime is NOT decided by n <= 10.

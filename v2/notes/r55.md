# r55: explicit constants for the k>=3 cluster bound O(L^3/n^2) (step 2 of r52)  -- partial; NOT a full proof

Script: `v2/scripts/r55_cluster_constants.py` (mpmath, re-run). main.tex/STATUS.md untouched.

## Setting (from r36/r52)
Z = sum_{S matching in host H} prod_{e in S} w_e * q_|S| = E_t[Xi(t w)], t=1/g^2, g^2/2~Gamma((n+1)/2) (exact, r52 step 1).
H has max degree <= L (host F u U), m <= nL/2 edges, omega := max|w_e| = max(|x-1|,1).
Xi(tw) = monomer-dimer gas, polymers = single edges, z_e = t w_e, two polymers conflict iff they share a vertex (or equal).
Closed neighbourhood of an edge has size Delta <= 2L-1.

## Proved (elementary, constants explicit)  -- "proof-grade"
**Lemma A (Penrose tree bound).** ln Xi(tw) = sum_{k>=1} c_k t^k, with the cluster sum absolutely convergent when rho := e*Delta*omega*t < 1, and
  sum_k-clusters |phi^T| prod|z| <= b_k := (m/Delta) * rho^k / k^2.
Proof: Penrose's bound |phi^T(gamma_1..gamma_k)| <= (1/k!) * #spanning trees of the conflict graph; swap the sums: <= (1/k!) sum_{labelled trees T on [k]} #(tuples compatible with T) <= (1/k!) k^{k-2} m Delta^{k-1} |z|^k; and k^{k-2}/k! <= e^k/k^2 (k! >= (k/e)^k). This is the standard textbook argument (Penrose 1967; Friedli-Velenik Thm 5.x); I wrote the counting, did not re-derive Penrose's inequality.
**Corollary (k>=3 tail).** For t <= 2/n and rho_0 := 2e*Delta*omega/n < 1:
  |R3(t)| := |sum_{k>=3} c_k t^k| <= (m/Delta) * rho_0^3 / (9 (1-rho_0)).
With m<=nL/2, Delta=2L-1 (so m/Delta <= n/2 for L>=1; use Delta<=2L): |R3| <= 4e^3 omega^3 (2L)^3 / (9 n^2 (1-rho_0)) ~ **71.4 omega^3 L^3/n^2 /(1-rho_0)**.
So the L^3/n^2 *order* with an explicit (crude) constant is proof-grade for the cluster remainder at fixed t in the window t<=2/n. Needs L = o(sqrt n) only for rho_0<1 (rho_0 ~ 4e omega L/n, actually L<=c n suffices here).

## Consequence, also elementary
If |R3|<=eps on t<=2/n then |ln E_t[e^{A(t)+R3(t);t<=2/n}] - ln E_t[e^{A(t)};t<=2/n]| <= eps, A(t)=c1 t + c2 t^2. (Trivial.)

## Still SKETCH (not proved here)
1. **Tail t>2/n** (r52 step 3): needs the bound sum_k m_k(|w|)q_k P_k(tail) <= e^{-cn} with constants. Only numerics (r52 b). Not written.
2. **Gamma-cumulant step**: ln E_t exp(c1 t + c2 t^2) - [c1 q1 + c2 q2 + (q2-q1^2)c1^2/2] = O(L^3/n^2). Power count: Var t ~ 2/n^3, Cov(t,t^2) ~ 4/n^4, c1~nL, c2~nL^2 gives L^3/n^2 for each of the m>=3 cumulants / cross terms; no analytic bound with constants (needs bounds on t-cumulants kappa_j(t) ~ j!/n^{2j-1}-type and a convergence radius; Gamma-inverse has no mgf at s>0, so the expansion is only valid on the window and needs a truncation argument). r52 (c) numerics: remainder = L^3/(3n^2) for the c1-only part.
3. Interplay with gaps 1/3/4 (overlap tail, m_j linearisation, x range) untouched. Host assumption: arbitrary graph max degree L; if the host degree is not bounded (random G(n,p)-type degrees) Delta must be replaced by a degree-weighted version.

Findings:
- Penrose bound holds in every case, loose by a factor ~6 (consistent: the truncated k=3..6 sum scales as (L/n)^3*n*... as predicted).
- rem*n^2/L^3 is stable in n (0.0534->0.0536->0.0545 for L=5) and **bounded by 0.09 here**, so L^3/n^2 is the right order for the *whole* remainder, with observed constant ~0.01-0.08, far below the proved 71.4. Caveat: only components K_{L+1}, only x=2, w>0 (no cancellations from U); no overlapping-F/U or triangle-rich-but-connected hosts; n/2 matching degree included exactly.
- Scaling in L: 0.054 (L=5), 0.082 (L=7): grows mildly in L at fixed n^2/L^3 scaling, so L^3 is an upper order; not tested for L comparable to sqrt n.

## Verdict
PROVED (elementary, modulo Penrose's inequality as a quoted standard): k>=3 cluster remainder of the product-form gas at fixed t<=2/n is <= (m/(9 Delta)) rho_0^3/(1-rho_0) <= ~71.4 omega^3 L^3/(n^2(1-rho_0)).
NOT PROVED: tail t>2/n with constants; the t-cumulant step (second-order formula vs mixture); anything for gaps 1/3/4. Numerics support the claimed order for one host family only. Gap 2 stays OPEN until those two are written.

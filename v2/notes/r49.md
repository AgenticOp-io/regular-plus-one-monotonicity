# r49 — Re z <= 0 zero-free test (Conjecture HP) extended to n=9,10

Scripts: `scripts/r49_enum.c` (exact enumeration, 64-bit counts), `scripts/r49_roots.py`
(mpmath 50-digit roots). Raw output: `data/r49_enum_*.txt`, `data/r49_roots_*.txt`.
Validated: n=7,8 totals/histograms agree with `r47_leeyang.py` regs counts (19355, 465).
Hosts: cycles C_3..C_n and paths with 2..n-1 edges. P_H(z)=sum_j N_j z^j.
NEW vs r47: r47 skipped the Hamiltonian cycle host C_n (k=n); r49 includes it.

- **D=3,4,5 at n=8,9,10 (all 5 cases, every host): no counterexample.** Every root has Re z < 0.
  Re z=0 not reached; closest approach to the imaginary axis in these: max Re = -0.109 (n=8, D=4, C_8).
  Max-Re moves toward 0 as D grows relative to n (D=3: -0.55 at n=10; D=5: -0.18), so the margin is not growing with n.
- **Conjecture HP "Re z<=0" is FALSE as stated**, via D=2 (and its complement D=n-3): the Hamiltonian-cycle
  host has roots with Re z > 0 (n=9,10 D=2: Re up to 3.0, 3.9; n=7 D=4, n=9 D=6: Re 0.06). Also path9, n=10, D=2: Re 0.015.
  These are small-D / complement-small-D (degenerate) cases; r47 missed them by omitting k=n.
- For (7,4) and (9,6) the nearest root to z=1 is at 0.959 and 0.951 < 1, so the disc |z-1|<1 is NOT zero-free there either
  (but a disc of radius 0.95 about 1 is, for these hosts).
- Distance of nearest root to z=1 for D=3,4,5 is >1.17; it does not visibly grow like n/D (D=5: 1.18 at n=10).
  Not enough data to claim a trend.

## Labels
- numerics (exact counts): D in {3,4,5}, n in {8,9,10}, 16 hosts each: all roots Re z<0. Not a proof.
- false: "Re z<=0 for all D-regular hosts" (counterexample D=2 Hamiltonian-cycle host, n=9,10; complement D=n-3).
- open: whether Re z > 0 zero-freeness holds uniformly for D in a range D>=3, n-1-D>=3 (the only regime the paper needs).
  Only host types tested: cycles and paths on consecutive vertices; no random/other hosts; n<=10 is small.
- Not tested: n=11+, D=6,7 at n=10 coverage beyond complements (D=6..: complement of D=3..), arbitrary hosts, z near-zero search on polydisc (done in r47).

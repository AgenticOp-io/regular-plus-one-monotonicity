## (a) Tail t>2/n  -- PROVED (elementary), constants explicit
Abs. tail T := sum_{k<=(n-1)/2} M_k(|w|) q_k P_k, P_k = P(Gamma(a-k) < n/4), a=(n+1)/2 (exact: E[t^k; t>2/n] = q_k P_k). Put u_k=(omega m)^k q_k/k!.
1. k<=n/8: n-2i+1 >= 3n/4 so q_k <= (4/(3n))^k and sum u_k <= e^{(2/3)omega L}. Chernoff P(Gamma(b)<y) <= exp(b ln(y/b)+b-y), decreasing in b for b>y; with b>=3n/8, y=n/4: P_k <= e^{-0.0271 n}.
2. n/8<k<=n/2: u_{k+1}/u_k = omega m/((k+1)(n-2k-1)); (k+1)(n-2k-1) is concave in k, so u_k is decreasing-then-increasing and sum <= (n/2) max(u_{n/8}, u_end), P_k<=1.
   u_{n/8} <= (16 e omega L/(3n))^{n/8}; u_end <= n (e^2 omega L C/n)^{~n/2} (uses (n-1)!! >= 2^k k!/n); for omega L <= n/100 both are <= e^{-0.2 n}.
3. Hence T <= e^{omega L - 0.027 n} + n e^{-0.2n}. In the window Z >= e^{-C omega L}(1 - tail) so T/Z_abs-type relative tail <= e^{-0.02 n} for omega L <= n/1000 -- negligible against any L^a/n^b.
Numerics (A): exact T vs e^{-n/40}*Z_abs, n=100..800, omega L=1,4,10: bound holds in every case (T is 1e-5..1e-35).
Caveat: step 2's end-point constants are stated, not carried to the last digit; the claim needed (super-exponentially small) is robust.

## (b) Gamma-cumulant step -- REDUCED, NOT PROVED
Cleaner reduction found: expand Phi(t)=ln Xi(tw) about q1, tau=t-q1: Phi(q1+tau)=Phi(q1)+Phi' tau+Phi'' tau^2/2+O(Phi''' tau^3); Phi'~nL, Phi''~nL^2, Phi'''~nL^3 (Penrose, r55) and tau~n^{-3/2}, so Phi''' tau^3 ~ L^3 n^{-7/2} and Phi'' tau^2 fluctuation ~L^2/n^2: both <= L^3/n^2. Everything reduces to the pure case ln E exp(a tau), a=Phi'(q1)~nL.
Exact cumulants of t (from q_k, checked numerically): kappa2 ~ 2/n^3, kappa3 ~ 16/n^5, kappa4 ~ 240/n^7 (ratios 1.00005, 2.0002/2 ->1, 5.0009/5 ->1 at n=1e5; table in script). So a^3 kappa3/6 = L^3/(3n^2) for a=nL/2 (matches r52's 0.333), a^4 kappa4/24 = 0.625 L^4/n^3 -- of smaller order (L<<n).
Windowed numerics (B): ln E[e^{s t}; |nt-1|<=24/sqrt n] minus (q1 s + k2 s^2/2 + k3 s^3/6) equals k4 s^4/24 to 3 digits (e.g. n=1e5,L=20: 1.0006e-10 vs 1.0002e-10). So the series is a genuine cumulant series with the sizes claimed.
What is missing for a proof (precisely):
 1. A uniform bound on kappa_j(t), j>=5 (or Taylor-with-remainder to order K): needs E[e^{c|Y|}; window] = O(1), Y=a tau. Route: on |1-G|<=delta (G=chi2/n) 1/G-1 <= (1-G)+(1-G)^2/(1-delta); chi2 mgf gives E e^{nu(1-G)} <= exp(nu^2 (n+1)/n^2) = O(1) for nu=a/n<=sqrt n, quadratic term nu delta^2 small. Not written with constants.
 2. The ln(1+x) cancellation: at order 4 one needs mu4-3mu2^2 = a^4 kappa4 (exact, fine) but for K-th order each order needs its own cumulant bound kappa_j ~ C_j n^{1-2j}... only kappa2..kappa4 verified.
 3. With K=4 Taylor the remainder is ~L^5 n^{-5/2} per factor, total over L factors L^6 n^{-5/2}: o(1) only for L=o(n^{5/12}), not L=o(sqrt n). The full L=o(sqrt n) range needs the all-order cumulant bound of item 2.
So: tail PROVED; cumulant step reduced to bounds on kappa_j(1/chi2_{n+1}) and one mgf estimate; ranges o(n^{5/12}) plausible, o(sqrt n) open. Gap 2 stays OPEN (also gaps 1/3/4 untouched, and the Penrose inequality is quoted).

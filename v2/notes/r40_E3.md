# r40: E3 re-derived with explicit D; true site weight w=(D^2-1)/4 and bundle-level free-site accounting
Status: **E3' below is derived line by line at proof level for the ordered-tuple count; steps marked (sketch) are not written out.** It replaces r30's crude 2D^4 weight by w=(D^2-1)/4 and the free-site factor (8l^3)^{D^2 t} by a bundle count. Consequence: r30's range D <= c (ln n)^{1/4} extends to D <= sqrt(ln n) - 4 ln(3 ln n) - O(1) (constant explicit, see Range), conditional on the same remaining r30/r38 items (listed at the end). Nothing beyond sqrt(ln n) is claimed.
Numerics: v2/scripts/r40_E3_check.py (exact fresh means, Monte Carlo moments, range table).

## Setting (as r25)
d on [n], d<=D, N=sum d, class = D-regular or D-2 on k vertices (N >= Dn-2k). l! E binom(X+Y,l) = sum over ordered l-tuples of distinct sites of P(all present) <= 2 sum N^{-m} (F_m(N) >= N^m/2, needs m^2 <= N/2). Read the tuple left to right; site i adds p_i new pairs, q_i new vertices; fresh / free / defect as in r25.

## Step 1: fresh weight is exactly lam1+lam2 = (D^2-1)/4 (PROVED)
Fresh loop: n vertices x C(D,2) point pairs / N = (D-1)/2 = lam1. Fresh double (unordered {u,w}, 2 points each, 2 matchings): (n^2/2) C(D,2)^2 2 / N^2 = (D-1)^2/4 = lam2. A fresh position is a loop or a double, so its total weight is w = lam1+lam2 = (D^2-1)/4 <= D^2/4, versus r25's 2D^4 (which charged D^2 points per vertex twice and a spurious factor 2). Checked: exact E X, E Y (script) and MC E[(X+Y)_l]/w^l = 0.94..1.00 for l<=4, D=3,4,6, n=400 (leading order, as it must be).
Correction to the r30 remark: r30 said the true weights are "D/2 (loop) and D^2/4 (double)". Exact values are (D-1)/2 and (D-1)^2/4; the sum is (D^2-1)/4 as above.

## Step 2: defect-site weights (PROVED for the list; ordering constants sketch-level)
Old vertices <= |V| <= 2l, unused points <= D each.
- (a) loop at old vertex (p=1,q=0... p-q=1): |V| C(D,2)/N <= l(D-1)/n.
- (b) double, one old, one new vertex (p=2,q=1): |V| n C(D,2)^2 2/N^2 <= l(D-1)^2/n.
- (c) double on two old vertices, p new pairs: p=1: C(|V|,2) x (existing pair, <= D) x (new pair, <= D^2/N = D/n) <= 2l^2 D^2/n; p=2: <= l^2 (D-1)^2/n^2.
Every defect site has weight <= 2 l^2 D^2 n^{-(p-q)} (vs r25's 4 l^2 D^4/n), p-q in {1,2}. Positions among l: <= l each. So per unit of n^{-1}: 2 l^3 D^2.

## Step 3: free sites by bundles (PROVED; this is the new idea)
A bundle = the set of pairs joining a given {u,w}; size b <= D. A free site picks two existing pairs of one bundle, so the number of choices at any time is <= sum_i C(b_i,2) <= ((D-1)/2) m <= (D-1) l. Free weight per position <= D l (r25: 4 l^2 D^2).
Cost accounting: a bundle reaches size b >= 3 only through (c)-sites that add pairs (a fresh or (b) site creates it with 2 pairs; a (c) site creating it with p=2 costs n^-2 and then size 2). Each added pair costs a factor 1/n via p-q >= p. So bundle i of size b_i carries n^{-(b_i-2)}, and its free sites number <= C(b_i,2). Therefore with total defect delta = sum(p_i-q_i):
 f <= sum_i C(b_i,2) <= delta * max_{3<=b<=D} C(b,2)/(b-2) <= D delta   (r25 had f <= D^2 t; checked max <= D numerically for D<200; analytically C(b,2)/(b-2) = b(b-1)/(2(b-2)) <= b).
The extra gain over r25: the cost is n^{-delta} with delta >= b-2, not just t >= 1.

## E3' (statement)
For l <= L+1, with rho_l = 2 l^3 D^2 (D l^2)^D and rho_l <= n/2:
 l! E binom(X+Y,l) <= 2 w^l (1 + R_l),  R_l <= sum_{delta>=1} (rho_l/n)^delta <= 2 rho_l/n,
and restricted to total defect >= 2: <= 2 w^l * 2 (rho_l/n)^2.
Derivation: sum over patterns: fresh positions give w^{l-t-f} <= w^l (w>=2 for D>=3), defect positions l^t (2l^2D^2 n^{-(p-q)})^t, free positions l^f (D l)^f; t <= delta, f <= D delta, so each unit of delta costs <= 2 l^3 D^2 (D l^2)^D / n = rho_l/n (bases >= 1). (The ratio of consecutive terms uses only this per-unit bound; the geometric sum is what is written.)
Not done (sketch): the p=2 and (b)-types were bounded by the same per-unit form without separate tuning; a tight constant is not claimed. The positions-times-choices count l^f (Dl)^f is lossy (counting sets of free sites rather than ordered tuples would give 2^{C(b,2)} per bundle, independent of l), but then needs a canonical ordering of the free sites, which I did not write.

## Truncation, collision remainder, error factor
- Truncation: L = max(ceil(e^2 w), ceil(3 ln n)): tail <= 4 (e w/(L+1))^{L+1} <= 4 e^{-(L+1)} <= 4 n^{-3} (this is where w, now D^2/4, instead of D^4 sets L; so L ~ 3 ln n as soon as D^2 <= 1.6 ln n).
- Collision remainder (r32, uniform in D): <= 2 l^4 * 2 w^l (1+R_l)/(l! n^2); sum_l l^4 x^l/l! <= 15 max(x,1)^4 e^x, so total <= C w^4 e^{w}/n^2: polynomial times e^{w}.
- delta >= 2 terms: n^{-2} sum_l 4 w^l rho_l^2/l! <= 4 rho_L^2 e^{w}/n^2. Define
 E'(n,D) = e^{w} rho_{L+1}^2 (times absolute constants), ln E' = (D^2-1)/4 + 2[ln 2 + 3 ln(L+1) + 2 ln D + D(ln D + 2 ln(L+1))] + O(1).
 Compare r30: ln E = 5D^4 + (3D^2+7) ln ln n. The D^4 and the D^2 ln ln n are both gone; ln E' = D^2/4 + O(D ln ln n).

## Range (what is proved, conditional on the list below)
Needed (G1'): rho_{L+1} <= n/2: D(ln D + 2 ln(L+1)) + 3 ln(L+1) + 2 ln D + ln 2 <= ln n - ln 2, i.e. D <~ ln n/(2 ln ln n). Not binding.
Needed for the L1 error (r30: e^{-G0} E/n^2 with e^{-G0} = e^{lam1+lam2} = e^{w} exactly): e^{2w} rho^2 C <= n^{1/2}, i.e.
 D^2/2 + 2 ln rho_{L+1} + ln C <= (1/2) ln n, so D <= sqrt(ln n) - 4 ln(3 ln n) - O(1) (leading order).
Under that range the r30 theorem reads: E C_k = (D-1)^k/(2k) (1 + f1(k)/n + O_K(n^{-3/2})) for 3 <= D <= sqrt(ln n) - 4 ln(3 ln n) - O(1), same f1. The exponent 3/2 is a choice; any D <= (1-eps) sqrt(ln n) with n large gives o(n^{-1}) error.
Numeric range (r40 script, constants: C = 200 in the error condition, rho at l = L+1): ln n=2303 (n=1e1000): D_new=20 (r30: 3); ln n=23026: 106 (r30: 6); ln n=2.3e5: 418 (12); 2.3e6: 1441 (21); sqrt(ln n) = 48, 152, 480, 1517. As with r30, practically asymptotic: no admissible D>=3 below ln n ~ 1000.

## Why sqrt(ln n) is the new barrier
e^{-G0} = e^{w} (L1 divides by P_d ~ e^{-w}) and E' contains another e^{w} from sum w^l/l!: error e^{2w} = e^{(D^2-1)/2}. Both factors are intrinsic to absolute-value Bonferroni: P = e^{-w} is exponentially small while sum of |terms| is e^{+w}. Beating sqrt(ln n) needs the cumulant/cluster route (r29/r36), not better weights.

# r45: numerical check of r43 gap 3 (backward-recursion sensitivity) -- PARTLY CONFIRMED, one claim CONTRADICTED

Script: `v2/scripts/r45_sensitivity.py` (float64, linear regime, x=2, n=1e4,1e6, L<=300 with L^2<=n/2).
Model used: the leading form gamma_k(y) = -(y-1)/(n-1) from r36 s3 (NOT the true o_v-dependent gamma_k, so this tests
the recursion's structure only), and S = sum_j j(y_j-1) as a proxy for sum_j ln Z_j (f_j'(y) ~ j since kappa1 ~ L^2/2;
that proxy is my assumption).

| quantity | measured | r43 claim |
|---|---|---|
| Lipschitz const of y->G(y) (row sum) | ~ x L/n (ratio to L^2/n: 0.18 at L=10 down to 0.007 at L=300) | O(L^2/n): **confirmed**, in fact O(L/n) |
| max_j |dy_j| per unit delta (delta added to every gamma_k) | 1.80, 1.92, 1.98, 1.99 for L=10,30,100,300 i.e. ~ x L delta | O(L delta): **confirmed** |
| dS per unit delta | ~ L^3/3 (3.3, 10.0, 33.3, 100.0 times L^2) | "ln Z_j changes by O(L)*dy_j": per factor yes, but see below |

Contradicted/sharpened: with delta = L^3/n^2 (r41 s4) in every gamma_k, each dy_j ~ L^4/n^2 (fine), but the SUM over
the L factors gives dS ~ L^3 delta/3 ~ L^6/n^2, which is o(1) only for L = o(n^{1/3}), not L = o(n^{1/2}). r43's
"contraction is plausible" is right (the map is a strong contraction), but the final total error is not
L^4/n^2 unless the per-gamma errors delta_k are much smaller than L^3/n^2 or are not summed coherently (random signs would
give ~L^{9/2}/n^2... still > L^4/n^2). So the o(1) range claimed for gap 3 needs delta_k = O(L^1/n^2)-type bounds, or a
cancellation argument.

Verdict: contraction/Lipschitz claim CONFIRMED (on the leading-order model); total-error claim INCONCLUSIVE-to-
CONTRADICTED depending on delta_k size and on the S proxy. Not tested: true o_v statistics, signs of delta_k, n<=1e4 with L large.
